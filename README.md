## 📌 Project Overview

**E-Commerce Web Application** is a modern, responsive single-page application (SPA) front-end built using **React**, **Tailwind CSS**, and **Vite**. 

The application provides a seamless shopping experience featuring product discovery, categorization, interactive product cards, and dynamic shopping cart management.

## ✨ Features

- 🏪 **Interactive Product Catalog**: Clean grid presentation of products with images, pricing, and details.
- 🔍 **Category Navigation**: Seamless client-side routing between product categories using **React Router v6**.
- 🛒 **Shopping Cart State**: Dynamic add-to-cart, remove-from-cart, and quantity modification.
- 📱 **Mobile-First Responsive Layout**: Optimized UI designed with **Tailwind CSS** for smartphones, tablets, and desktop displays.
- ⚡ **Lightning Fast Builds**: Powered by **Vite** for instant Hot Module Replacement (HMR) and optimized production bundles.

## ⚙️ Installation & Local Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/)

### 1. Clone the Repository
```bash
git clone https://github.com/akhileshyadav865722/ecommerce-application.git
cd ecommerce-application
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```

Open your browser and navigate to `http://localhost:5173`.

### 4. Build for Production
```bash
npm run build
```
